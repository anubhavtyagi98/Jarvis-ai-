# JARVIS AI

A privacy-first personal AI assistant that brings chat, voice interaction,
document understanding, coding help, tasks and user-controlled memory into
one secure workspace.

> Status: architecture and design complete; implementation in progress.

## Key features
- Streaming AI chat with conversation history
- Push-to-talk and configurable wake phrase
- Document upload and Q&A with page/snippet citations
- Opt-in memory you can view, edit, pause and delete
- Tasks and reminders
- Approval required before any sensitive or external action

## Tech stack
React + TypeScript + Vite | FastAPI | PostgreSQL | Docker Compose
